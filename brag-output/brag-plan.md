# /brag plan — Roamly

**Source:** https://roamly.rainwater.gg (live site + its built-in "Try a demo" trip)

## Answers
- **What is it?** A web + Android app for planning trips with friends: a shared itinerary, lists, notes and photos.
- **Who's it for?** Any group going somewhere together who are currently planning it in a group chat.
- **What sets it apart?** Everything for one trip lives in one shared place: day-by-day plans with the weather, "open" plans anyone can join, who's-bringing-what lists, a pinned notes board, one photo album.
- **Most impressive claim:** "Everything for the trip, in one place."
- **Visual hook:** group-chat chaos (cooler? wifi? dinner?) answered by the calm beach illustration.
- **Real UI shown:** the demo trip "Sample trip: beach weekend" — Plan tab (tap *Join* → 3 going), Lists tab (tick *Beach towels* → 3 of 5 packed), Board and Photos tabs.
- **Tone:** `default` — warm, playful, clean. Matches the app's sand/teal/sun palette and its own copy ("A little plan, lots of fun.").
- **Share caption:** see `share-copy.txt`.

## Data / privacy
All UI is the public demo trip, already fictional (Joe, Sam, Alex, door code 0000, SAMPLE-1234). The "DEMO" banner is removed. The Explore tab is skipped because it lists real local businesses. No real users, emails or internal URLs appear.

## Music
120 BPM (beat = 0.5s, bar = 2s), D major, breezy beach-pop: marimba-like pluck arpeggio, round bass, soft kick/snap, quiet shaker. I–vi–IV–V (D–Bm–G–A). Effects in key: chat-bubble pops (A5/D6/F#6), a soft whoosh into the reveal, wood-tap "clicks" on the two UI taps, a final chord ring-out. Every cut lands on a beat.
